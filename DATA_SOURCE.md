# Data source

## Where the data come from

All analyses use the **eICU Collaborative Research Database v2.0** (eICU-CRD), a
deidentified multicenter database of ICU admissions to 208 US hospitals during
2014 and 2015, released through PhysioNet.

- Database: <https://eicu-crd.mit.edu>
- PhysioNet record: <https://doi.org/10.13026/C2WM1R>
- Reference publication: Pollard TJ, Johnson AEW, Raffa JD, Celi LA, Mark RG,
  Badawi O. The eICU Collaborative Research Database, a freely available
  multi-center database for critical care research. *Sci Data* 2018;5:180178.
  <https://doi.org/10.1038/sdata.2018.178>

## Why no data are in this repository

Access is governed by the **PhysioNet Credentialed Health Data Use Agreement**.
Row-level records may not be redistributed. Everything under `data_private/` is
therefore gitignored and must be regenerated locally by anyone reproducing this
work.

To obtain access you must:

1. Create a PhysioNet account and complete the CITI "Data or Specimens Only
   Research" training.
2. Sign the Credentialed Health Data Use Agreement for eICU-CRD.
3. Query the database directly, or through the Google BigQuery mirror
   (`physionet-data.eicu_crd`), which is what the SQL in `sql/` targets.

## Regenerating `data_private/`

Run the three queries in `sql/` against `physionet-data.eicu_crd` and save each
result as CSV into `data_private/`:

| Query | Output | Contents |
|---|---|---|
| `sql/01_build_cohort.sql` | `cohort_raw.csv` | One row per qualifying ICU stay: assessment flags, patient covariates, hospital characteristics |
| `sql/03_delirium_strict.sql` | `delirium_strict.csv` | Per stay, the two delirium fields split — validated instrument vs nursing impression |
| (see below) | `stay_year.csv` | `patientunitstayid`, `yr` from `patient.hospitaldischargeyear` |

`sql/02_delirium_label_audit.sql` is an audit query used to establish which
nursing chart fields carry assessments. It does not produce a pipeline input,
but rerunning it reproduces the label enumeration described in the Methods.

The `stay_year.csv` extract is a single query:

```sql
SELECT patientunitstayid, hospitaldischargeyear AS yr
FROM `physionet-data.eicu_crd.patient`
WHERE unitvisitnumber = 1
  AND unitdischargeoffset >= 1440
  AND (SAFE_CAST(age AS INT64) >= 18 OR age = '> 89')
```

With `bq` installed and authenticated:

```bash
bq query --use_legacy_sql=false --format=csv --max_rows=1000000 \
  "$(cat sql/01_build_cohort.sql)" > data_private/cohort_raw.csv
```

## Cohort definition

First ICU admission per hospitalization, adults (age >= 18, including the
aggregated `> 89` category), ICU length of stay >= 24 hours.

**110,257 stays across 208 hospitals**; 190 hospitals contribute at least 25
stays and are characterized individually; 173 contribute at least 15 stays in
both calendar years and enter the paired year-on-year analysis.

## Outcome fields

Assessment documentation is taken from `nursecharting` within the first seven
ICU days. All 65 distinct `nursingchartcelltypevallabel` values in that window
were enumerated and inspected before the matching rules were fixed:

| Element | Fields matched |
|---|---|
| Delirium, **validated** (primary) | `Delirium Scale/Score` — holds CAM-ICU and ICDSC results |
| Delirium, permissive (secondary) | the above **plus** `Symptoms of Delirium Present`, a yes/no nursing impression that is not a validated instrument |
| Sedation | `Sedation Scale/Score/Goal`, `SEDATION SCORE`, `RASS` |
| Pain | four pain-scoring fields, including behavioral scales |

`Mental Status Assessment` and `Neurological Assessment` were inspected and
**excluded**: their recorded values are checkbox entries (`X`, `WDL`) rather
than instrument results.

The two delirium fields are mutually exclusive at the level of the individual
stay; no stay carries both.

## Data protection

- No row-level data leaves the analysis environment.
- `data_private/` is gitignored, as are all `.csv` files by default.
- Results objects (`results/*.rds`) are also gitignored: they are derived from
  patient data and are regenerated by `run_all.R`.
- Hospitals are identified only by the deidentified `hospitalid` supplied by
  eICU-CRD. Note that these identifiers partly encode the contributing health
  system, which is itself a finding reported in the paper.

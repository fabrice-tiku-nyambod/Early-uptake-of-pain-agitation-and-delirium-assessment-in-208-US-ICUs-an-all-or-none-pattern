# Superseded scripts

Kept for provenance; **not part of the pipeline** and not run by `run_all.R`.

- `01_describe.R` — the first descriptive pass. Superseded by `12_tables.R`.
  It reports the *permissive* delirium definition (21.8%), which is no longer
  the paper's primary outcome, so running it produces numbers that do not match
  the manuscript. That is why it is archived rather than maintained.
- `11_figures.R` — the first figure set (uptake spaghetti, adoption forest,
  case-mix Love plot). Superseded by `16_figures_v2.R`.
